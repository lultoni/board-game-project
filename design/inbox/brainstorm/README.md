# Inbox — Brainstorm Dump

Drop your raw brainstorming here. One `.md` file per brainstorm session — whatever name you like (`2026-06-22-game-shape-thoughts.md`, `digital-prototype-controls.md`, etc.).

## How to use

- **Brand new thought?** Create a new file. Date in the filename helps but isn't required.
- **Continuing an earlier thought?** Append to the existing file.
- **No structure required.** Bullets, prose, fragments, sketches — whatever you'd write in a notebook.

## What happens next

At session end (or whenever you ask), I'll:
1. Read every file in this folder.
2. Distill load-bearing ideas into `backpocket` entries, OQs, or essays in `design/design.db`.
3. Either delete the source file (if fully absorbed) or leave a pointer back to its DB destination.

Think of this folder as the "fast-write" channel. The DB is the "slow-write" channel. Don't optimise files here — just dump.

## Examples of what fits here

- Mid-shower idea: "what if Bodyguard auto-triggered on Strikes too?"
- Holiday reflection: ten-minute riff on game shape.
- A reference to another game you played and what it made you think about.
- A worry that surfaced and you don't want to lose.

## What doesn't fit here

- Anything already in the DB (don't restate — link or update).
- Playtest data (goes in `playtest-results/` then into `playtests` table).
- Finalised design decisions (those go straight to `adrs` / `mechanics` / `stacks`).
