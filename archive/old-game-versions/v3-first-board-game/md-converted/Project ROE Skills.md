## Shorthand Legend

| Short    | Meaning                                           |
|----------|---------------------------------------------------|
| POP      | Piece on Path (first piece along the Skill Path)  |
| P        | Piece                                             |
| Opp      | Opponent                                          |
| Adj      | Adjacent (up to 8 tiles, diagonals allowed)       |
| AllAdj   | All orthogonally adjacent tiles                   |
| Sq       | Square / tile                                     |
| R / Rx   | Range / Range of x tiles                          |
| SP       | Skill Path (straight queen-line, no curves)       |
| Pull1    | Pull target 1 tile toward caster                  |
| Push1    | Push target 1 tile away from caster               |
| SwapAdj  | Swap with adjacent ally                           |
| Rune−    | Remove 1 Rune from target                         |
| Self     | Caster itself                                     |
